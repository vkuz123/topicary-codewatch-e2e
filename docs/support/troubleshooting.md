Common issues and their solutions.

Issue: 401 Unauthorized — Check that your API key is valid and included in the Authorization header.

Issue: 429 Too Many Requests — You have exceeded the rate limit. Implement exponential backoff.

Issue: CORS errors — Ensure you are using a publishable key for client-side requests.
